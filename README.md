# GitHub Copilot for Eclipse Feedback

[GitHub Copilot for Eclipse](https://marketplace.eclipse.org/content/github-copilot) is your AI-powered coding assistant, designed to enhance your development experience. Leveraging advanced language models, it provides intelligent code completions and chat-based assistance directly within your Eclipse IDE.

This repository is for providing feedback on the GitHub Copilot for Eclipse, including Copilot Chat, completions, Agent Mode, MCP and other features. You can use this repository to report issues or submit feature requests related to the user experience and interface of either extension.

Learn more about [GitHub Copilot](https://github.com/features/copilot) in our [docs](https://docs.github.com/copilot/using-github-copilot/getting-code-suggestions-in-your-ide-with-github-copilot?tool=eclipse).

## Providing Feedback

You can use this repository to file issues for GitHub Copilot for Eclipse. We welcome all types of feedback, including:

* Up-vote a feature or request a new one.
* Search for existing issues already reported for potential workarounds.
* Report a problem if you don't find what you are looking for.
